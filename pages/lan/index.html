📶 LAN version

Host on one device; everyone joins over the same Wi-Fi. Best for 3–5 players.

Why this one isn't hosted here

The LAN version needs a small server running on a computer (or Android phone) — GitHub Pages only serves static files, and a secure (HTTPS) web page can't talk to a local server anyway. So you run it yourself; it takes one command. Want zero setup instead? Use the peer-to-peer version.

Run it (macOS — easiest)

  1. Get the project from GitHub.
  2. Double-click Deep Sea Crew.app (or launch-deep-sea-crew.command) in the project folder.
  3. It prints a Wi-Fi URL like http://192.168.1.16:3000.
  4. Everyone opens that URL on their phone (same Wi-Fi). One person creates a crew, shares the 4-letter code; others join.

Run it (any OS — terminal)

git clone https://github.com/wey-typ/dsc-p2p
cd dsc-p2p
npm install
npm run play   # builds the client + starts the server on :3000

No router? Turn on the host device's personal hotspot and have everyone join that — the LAN works over the hotspot.

What you get

Full game: 2–5 players, levels with rules guide, sonar, save/resume, leaderboard, bots, reconnect, sound & music. The peer-to-peer version shares the same gameplay but trades the server for a direct device-to-device link.
